Tecnologias do desenvolvimento web

HTML

O HTML (HyperText Markup Language) é uma linguagem de marcação utilizada para construir a estrutura de páginas da internet. Ele organiza os elementos apresentados ao usuário, como títulos, parágrafos, imagens, links e formulários.

Um documento HTML possui duas partes principais: o Head, que contém informações e configurações da página, e o Body, onde ficam os elementos exibidos no navegador.

Podemos comparar o HTML ao esqueleto de um corpo humano, pois ele organiza toda a estrutura de um site. O arquivo principal geralmente é chamado de index.html.

Exemplo de HTML:

<h1>Olá, mundo!</h1>
<p>Este é meu primeiro site.</p>

CSS

O CSS (Cascading Style Sheets) é utilizado para definir a aparência de uma página HTML. Enquanto o HTML organiza o conteúdo, o CSS cuida da parte visual.

Com ele, podemos mudar cores, fontes, tamanhos, espaçamentos, bordas e fundos.

O CSS pode ser escrito dentro do HTML ou em um arquivo separado com extensão .css.

Podemos comparar o CSS à pele e às roupas de um corpo, pois ele deixa a estrutura mais bonita e organizada.

Exemplo de CSS:

body {
    background-color: aqua;
    font-family: Arial;
}

h1 {
    color: darkgreen;
    text-align: center;
}

JavaScript (JS)

O JavaScript é uma linguagem de programação utilizada para adicionar interatividade às páginas da internet. Ele permite que o site execute ações de acordo com as interações do usuário.

Com JavaScript, podemos criar contadores, calculadoras, jogos, animações e menus interativos.

A linguagem utiliza variáveis, funções, condições e estruturas de repetição.

Podemos comparar o JavaScript aos músculos e ao sistema nervoso de um corpo, pois ele permite que os elementos realizem ações.

Exemplo de JavaScript:

let contador = 0;

function aumentar() {
    contador++;
    console.log(contador);
}
